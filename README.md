# Homework Dashboard

A simple web app to enter class-wise daily homework and print it, save it as PDF, or share it (A4, as many copies per page as fit).

## Run locally
```
pip install -r requirements.txt
python app.py
```
Open http://localhost:8000

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. In Vercel choose **Add New > Project**, import the repository and click **Deploy** (Vercel detects the Flask app in `app.py`).
